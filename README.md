## 📌 Overview

This project predicts whether a person is **diabetic or not** using Machine Learning.
It helps in **early detection**, which is crucial for better treatment and prevention.

---

## 🎯 Problem Statement

Diabetes is a growing health issue. Early prediction can help in timely diagnosis and treatment.
This system uses patient medical data to **predict diabetes accurately**.

---

## 📊 Dataset

| Feature                    | Description           |
| -------------------------- | --------------------- |
| Pregnancies                | Number of pregnancies |
| Glucose                    | Blood sugar level     |
| Blood Pressure             | BP level              |
| Skin Thickness             | Skin fold thickness   |
| Insulin                    | Insulin level         |
| BMI                        | Body Mass Index       |
| Diabetes Pedigree Function | Genetic influence     |
| Age                        | Age of patient        |
